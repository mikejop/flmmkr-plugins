Put the OCIO config for ACES 1.x projects here, named config.ocio
(e.g. a cg-config / studio-config built for ACES 1.3, OCIO v2).
In the plugin: ACES Version = "ACES 1.x (legado)" and OCIO Config = this file.
Keep it in sync with the ACES version chosen in DaVinci Resolve > Project Settings > Color Management.
